# Tecsystem — site estático

Landing page desenvolvida somente com HTML, CSS e JavaScript.

## Executar localmente

Abra `index.html` diretamente no navegador ou use:

```powershell
python -m http.server 3000
```

Depois acesse `http://localhost:3000`.

## Estrutura

- `index.html`: conteúdo e SEO.
- `styles.css`: layout e responsividade.
- `script.js`: menu, máscara, validação e envio ao WhatsApp.
- `assets/`: imagens, ícones e logo.
- `servicos/`: páginas específicas para campanhas e SEO.
- `politica-de-privacidade.html`, `termos-de-uso.html` e `politica-de-garantia.html`: transparência e conformidade.
- `CONFIGURACAO-PUBLICACAO.md`: checklist de domínio, sitemap e mensuração.
- `BackupSiteOld/`: versão anterior em React/Vinext.
